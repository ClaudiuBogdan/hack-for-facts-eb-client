# PERF-018: Main pages' route code carries modules the page never runs on first load (SheetJS, other views, both locales' data, a Markdown renderer, a dialog barrel)

## Summary

Each main page's route chunks must arrive before hydration, and on mobile they come in the late serial wave
([PERF-005](PERF-005-lazy-route-code.md)). Several pages' route chunks statically import code that the first view never uses:

- a spreadsheet parser on a read-only map;
- a second view's components;
- both languages' classification JSON;
- a Markdown renderer behind an info link;
- a barrel that brings framer-motion and Radix Dialog.

Each is a static import that a `lazy()`, a dynamic `import()` or a narrower import path would remove.

## Where

- **Pages and route code:**
  - `/map`: `map.lazy` → `map-analytics-workspace`;
  - `/entity-analytics`: `src/routes/entity-analytics.lazy.tsx`;
  - `/charts`: `src/routes/charts/index.lazy.tsx`;
  - `/justice`: the justice hub's imports from `home-chrome.tsx`;
  - `/legislation`: `legislation-shell.tsx`;
  - `/parlament`: `parliament-page.tsx` and `use-parliament-data.ts`;
  - `/primarie`: the campaign selector;
  - the hubs: the search's `entity-tags.json`.
- **Files:** the cause column of the table below.
- **Domains:** local budgets, justice, legislation, parliament, NGOs and the other hubs, the town-hall campaign.

## Root cause

Static imports chosen for convenience, such as one helper imported from a module with heavy top-level imports.
Route chunks include their whole static closure, and on these pages that closure loads before hydration.

## Proposed fix

1. **`/map`:** move the formatter to its own module, or `await import('xlsx')` and `import('papaparse')` inside
   the parse functions.
2. **`/entity-analytics`:** `lazy()` the line-items/treemap view.
3. **Classification JSON:** load only the active locale, or load the labels on demand.
4. **Markdown renderer:** load it when a description is opened.
5. **`/charts`:** lazy-load the preview renderer, and read the store in an effect (or render the list
   client-only).
6. **Hubs:** import `entity-tags.json` dynamically.
7. **Justice:** import `HomeBand` and `HomeSectionNav` from `home-section-nav`, move `SHOW_MORE_CLASS` and the
   other small helpers into a leaf module, or move `ProcurementHomeSearchField` into its own file.
8. **Parliament:** `React.lazy` per tab; split the hooks and facade per surface; gate the mocks behind a
   compile-time constant with a dynamic `import()`.
9. **Data-trust components:** import `DataStatusBadge` from `@/components/data-trust/data-status-badge`, or
   declare `"sideEffects": ["*.css"]` app-wide after checking the build.
10. Add a bundle check (for example rollup-plugin-visualizer or `source-map-explorer` in CI) for these routes'
   closures.

## Expected impact

- **`/map`:** ≈−112 KB zstd before hydration, ≈−0.6 s mobile.
- **`/entity-analytics`:** ≈−120 KB, ≈−0.7 s mobile.
- **`/charts`:** ≈−29 KB.
- **`/justice`:** −67.6 KB, hydration ≈−0.45 s on mobile, for direct entries. A visitor coming from `/` already
  has the search cached.
- **`/legislation`:** −48.7 KB zstd, mobile hydration ≈−0.43 s.
- **`/parlament`:** ≈−55 to −65 KB gzip off the hub's critical path, ≈0.3–0.4 s on mobile.
- **Hubs:** ≈−9 KB each.
- **Desktop:** tens of ms.

## How to verify

2. The route wave KB (`tools/shared-metrics.py`) drops by the amounts above.
