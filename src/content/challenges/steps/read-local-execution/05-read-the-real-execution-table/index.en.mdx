# Read the Official Execution Table

## What an execution table shows

The platform presents execution data in a structured format that is easier to read than the official document. For expenditures, the key columns are: indicator name, functional code, economic code, and amount. For revenues, the structure is similar but without economic codes. This is the same logic you will find in an official report.

## The unit trap

Official budget documents use `thousand lei` as the base unit, not `lei`. That means `1250` in the table actually represents `1,250,000 lei`. A large amount can look small if you forget to check the unit in the document header or footer.

Another trap: the same amount may appear both at the total level and in the structure that breaks it down. That is not duplication, it is hierarchy.
