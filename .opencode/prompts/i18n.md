## Rules

- User-facing text in React code must use `t` or `<Trans>`.
- Do not manually edit `.po` files.
- Use `yarn i18n:extract` only when catalog updates are needed, and make clear that it mutates `src/locales/{en,ro}/messages.po`.
- Run `yarn i18n:compile` after catalog changes.
- Preserve Romanian and English locale coverage.

## Review Focus

- Hardcoded visible strings.
- Button labels, aria labels, toasts, empty states, table headings, filter labels, chart labels, and error messages.
- Dynamic messages that need interpolation rather than string concatenation.
- Copy that is too vague for public budget analytics users.
